# Appendix B Caption Snippet

Use the following caption for the NIST table in Appendix B.

```latex
\caption{
Input bitstreams and sequence partitions used for the NIST SP~800-22 statistical sanity check.
The repository files correspond to the extracted-output bitstreams archived in the Zenodo repository cited in the Data Availability Statement.
}
```

This version intentionally does not put `\url{...}` inside the table caption, because `\url` in a moving argument can cause LaTeX compilation errors.
